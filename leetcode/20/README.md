# Valid Parentheses

1. Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.
2. Add open brackets to stack when you encounter them, and for every closing bracket, check if it matches the top of the stack. If it does, pop the stack; otherwise, return false. At the end, if the stack is empty, return true; otherwise, return false.

TC/SC: O(n)/O(n)
