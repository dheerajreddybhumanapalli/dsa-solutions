# Smallest Index With Digit Sum Equal to Index

1. Get sum of digits of each number in the array through iteration and check if the sum is equal to the index of the number in the array.
2. If the sum is equal to the index, return the index.
3. If no such index is found, return -1.

TC/SC: O(n * d)/O(1) where n is the length of the array and d is the average number of digits in the numbers.
